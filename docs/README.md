# Documentation index

Documentation of the COE (*Certificado de Operações Estruturadas*) — the Brazilian
structured note. Start with the [repository README](../README.md) for the short version.

## Figures

All payoff drawings are SVG files in [figures/](figures/), generated by
[figures/generate_figures.py](figures/generate_figures.py). To change a drawing, edit the
script and re-run:

```bash
pip install matplotlib
python3 docs/figures/generate_figures.py
```

## Clearing documents

[clearing/](clearing/README.md) holds the official B3 documents that govern registration
and calculation of the COE — the *Manual de Operações*, the *Caderno de Fórmulas* and the
*Manual de Normas* — with links to the official sources and the naming convention for the
PDF copies kept in this repository.
