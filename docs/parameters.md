# Parameters of a COE

Every parameter that defines a COE, in two layers:

1. **Registration fields** — the instrument-level data registered at B3 (per the
   [Manual de Operações — COE](clearing/README.md));
2. **Payoff parameters** — the fields specific to each payoff figure, referenced by the
   registered formula (per the [Caderno de Fórmulas — COE](clearing/README.md)).

Cross-references: how each parameter enters the calculation is in
[calculations.md](calculations.md); which parameters each structure uses is in each
payoff document under [payoffs/](payoffs/README.md).

## 1. Identification and instrument-level fields

Field names below are the ones on B3's Registro/Emissão screen (*Manual de Operações —
COE*, version 20/07/2026, "Registro/Emissão" — the copy in
[clearing/](clearing/README.md)).

| Field (PT-BR, as registered) | Field (EN) | Description |
|---|---|---|
| Conta Emissora | Issuing account | The issuer's type-40 account at B3 (multiple/commercial/investment bank or caixa econômica). Registration is mandatory; issuance is exclusively book-entry. |
| Código IF | Instrument code | Generated by the system as `MMFFAAMSSSS`: issuer mnemonic (MM), **payoff figure code (FF)**, year (AA), month (M), sequential (SSSS). ISIN (`Código ISIN`) is optional. |
| Nome Fantasia | Commercial name | Free-text title of the note (alphanumeric, 100 positions). |
| Tipo do COE / Figura | Payoff figure | Which registered payoff figure applies (see [§4a](#4a-registered-payoff-figures-códigos-de-figura) and [payoffs/](payoffs/README.md)); determines the figure-specific fields ("Dados Específicos"). |
| Data de Emissão | Issue date | Business day (national calendar) the certificate is created. A forward-starting note also fills `Data Emissão a Termo`. |
| Data de Vencimento | Maturity date | Final settlement date; must be a business day. |
| Quantidade Emitida | Quantity issued | Integer number of certificates. |
| Valor Unitário de Emissão | Unit issue price | Price per certificate (12 integers, 8 decimals). |
| Valor Financeiro de Emissão (VFE) | Financial value of issuance | `Quantidade × Valor Unitário`. Rebates and several figure payoffs are registered as percentages of the VFE. |
| Modalidade | Modality | Registered as **Capital Investido Garantido** (≙ VNP) or **Perda Limitada ao Capital Investido** (≙ VNR) — see [overview.md](overview.md#3-modalities). |
| Capital Garantido (%) | Guaranteed capital | Percentage of capital guaranteed at maturity: **≥ 100%** when the modality is Capital Investido Garantido; **0 ≤ x < 100%** when it is Perda Limitada (partial protection is registrable). |
| Base Aplicação (%) | Protected-leg base | Percentage of the VFE allocated to the leg that protects the guaranteed capital (the funding leg) if the derivative is not exercised. |
| Posição do emissor no derivativo | Issuer's derivative position | Comprado (long) or Vendido (short) — whether the embedded derivative is an asset or liability of the issuer. |
| Tipo de Regime | Custody regime | DEPOSITADO or REGISTRADO. |
| Resolução CVM 8 | CVM Resolution 8 flag | "Sim" when the COE is the object of a public distribution under CVM Resolution 8/2020 (DIE required). |
| Entrega Física | Physical delivery | Optional, only for the Ações / Títulos Privados underlying classes. |

## 2. Underlying (ativo subjacente) fields

| Field | Description |
|---|---|
| Classe do Ativo Subjacente | Registered class — screen options: Taxas de Câmbio, Commodities, Ações, Índices, Ações Internacionais, Índices Internacionais, Cesta (basket). CMN Resolution 4,263/2013 requires prices/indices with public, regular and verifiable disclosure. |
| Ativo Subjacente | The underlying within the class (ticker / index / currency pair); "the appreciation index of the COE". For baskets, each component and weight is set up via Parametrização de Cestas (Rainbow baskets may carry positive, zero or negative weights). |
| Valor Inicial do Ativo Subjacente (S₀) | Initial price on which all percentage fields (strikes, barriers) apply. Mandatory for non-captured assets; for assets B3 captures, defaults to the previous business day's quote if left blank. Baskets always use 10,000. |
| Período de captura para liquidação | How the final fixing is formed — **Data Única** (single date), **Janela de Datas** (window of 1–5 business days ending up to 5 DU before maturity, taking the max/min/mean per `Tipo de Fixing para Vencimento`), or **Mais Datas** (an explicit schedule of dates). |
| Tipo de Cotação para Liquidação | Which quote of the day is used: Fechamento (close), Média, Máximo, Mínimo or Ajuste (settlement price). |
| Lookback / Critério de Lookback | Optional lookback on the initial value between two registered dates, with criterion Máximo, Média or Mínimo. |
| Variação Quanto | Mandatory for FX/international/basket classes: **Sim** = quanto (the asset's currency variation is *not* counted; local-currency performance paid in BRL), **Não** = composite (FX variation counted, with `Valor Inicial da Paridade` or a paridade fixing date registered). |
| Proteção contra Proventos | Corporate-action protection for stock underlyings: "Sim – Ajustado pelo Emissor", "Sim – Cetip" (automatic adjustment of S₀ for splits/bonuses) or "Não". |

## 3. Remuneration (fixed-income leg) fields

| Field | Description |
|---|---|
| Remunerador no Vencimento | The indexer that remunerates the unit issue price **at maturity only** — screen options: Sem remuneração, Pré, DI, IPCA VCP, IBOVESPA VCP, IBOVESPA, USD VCP, USD, No período, PRÉ LIN/360 + VC USD. Cash-flow (coupon) remuneration is registered separately as `Remunerador no Fluxo` in the Fluxo de Caixa section. |
| Remunerador Flutuante (%) (p) | The percentage applied to a floating indexer (DI, USD, IBOVESPA) — e.g. 90 for "90% of CDI"; enters the DI factor formula in [calculations.md](calculations.md#2-accrual-factors). |
| Spread/Cupom (%) (i) | Annual rate for Pré (or "No período") remuneration. |
| Base | Day-count basis of the Spread/Cupom: **252 exp** (DU/252 exponential — the standard Brazilian convention), **360 exp** or **360 lin**. |
| Fluxo de Caixa | "Sim" when the note pays interim events (coupons); the schedule and its `Remunerador no Fluxo` are registered in the cash-flow section. |

## 4. Payoff parameters (per figure)

The registered formula of each payoff figure references a subset of these fields. The
"used by" column points at the payoff documents.

| Parameter (PT-BR) | Symbol | Description | Used by |
|---|---|---|---|
| Participação | *Part* | Multiplier on the underlying performance passed to the investor (may be <, = or > 100%). | [call-participation](payoffs/call-participation.md), [call-spread](payoffs/call-spread.md), [put-spread](payoffs/put-spread.md), [shark-fin](payoffs/shark-fin.md), [twin-win](payoffs/twin-win.md) |
| Alavancagem / boost | *B* | Leverage factor on the upside of a booster (e.g. 2×). | [booster](payoffs/booster.md) |
| Cap (teto) | *Cap* | Maximum performance considered by the formula (caps the gain). | [call-spread](payoffs/call-spread.md), [put-spread](payoffs/put-spread.md), [booster](payoffs/booster.md) |
| Piso (floor de performance) | *Floor* | Minimum performance considered (bounds a loss leg). | VNR variants |
| Strike (preço de exercício) | *K* | Performance/price level from which the option leg starts paying; usually 100% of S₀ but may be set above/below. | all directional payoffs |
| Cupom / rebate digital | *C* | Fixed coupon paid when a digital condition verifies; rebate paid on knock-out. | [digital](payoffs/digital-duplo-indexador.md), [shark-fin](payoffs/shark-fin.md), [autocall-athena](payoffs/autocall-athena.md), [autocall-phoenix](payoffs/autocall-phoenix.md), [reverse-convertible](payoffs/reverse-convertible.md), [range-accrual](payoffs/range-accrual.md) |
| Memória de cupom | — | Whether missed coupons are recovered when a later coupon condition verifies. | [autocall-phoenix](payoffs/autocall-phoenix.md) |
| Barreira (nível) | *H* | Barrier level as % of S₀ (e.g. 70%, 130%). | barrier payoffs |
| Tipo de barreira | — | **Knock-in** (activates a leg) or **knock-out** (extinguishes a leg); direction **up** or **down**. | [shark-fin](payoffs/shark-fin.md) (up-and-out), [reverse-convertible](payoffs/reverse-convertible.md) / [autocalls](payoffs/autocall-athena.md) / [twin-win](payoffs/twin-win.md) (down-and-in) |
| Observação da barreira | — | **European** (final fixing only), **discrete** (scheduled dates), or **continuous** (any trading day). Materially changes risk and price. B3 registers this as `Período de Verificação de Barreiras` = **Europeia** (a single `Data para Fixing`) or **Americana** (daily verification between `Data Inicial/Final para Verificação`, with a registered quote type). | barrier payoffs |
| Trigger de autocall | *T<sub>i</sub>* | Level (usually 100% of S₀, sometimes step-down) that causes automatic early redemption on observation date *i*. | [autocall-athena](payoffs/autocall-athena.md), [autocall-phoenix](payoffs/autocall-phoenix.md) |
| Barreira de cupom | *H<sub>c</sub>* | Level above which the periodic coupon is paid. | [autocall-phoenix](payoffs/autocall-phoenix.md) |
| Datas de observação | *t₁…t<sub>n</sub>* | Schedule of autocall/coupon/range observations (e.g. semi-annual). | autocalls, [range-accrual](payoffs/range-accrual.md) |
| Range (banda) | *[L, U]* | Lower/upper bounds of the accrual range. | [range-accrual](payoffs/range-accrual.md) |
| Média (asiática) | — | Number and schedule of fixings averaged for S₀ and/or S<sub>T</sub>. | any figure may average fixings |

## 4a. Registered payoff figures (códigos de figura)

B3 registers each COE under a **figure code** (`COE001001`–`COE001088`; the `FF` element
of the Código IF). The figures are option *building blocks* named after the derivative
package, not the commercial names used in distribution — the annex "Descrição dos campos
das figuras" of the *Manual de Operações — COE* (from p. 120 of the committed copy)
defines the specific fields of each. A selection, with the commercial structures
documented in [payoffs/](payoffs/README.md) that map to them:

| Code | Registered figure | Commercial structure here |
|---|---|---|
| COE001001 / COE001064 | Call / Call com Participação | [call with participation](payoffs/call-participation.md) |
| COE001005 | Call Spread | [call spread](payoffs/call-spread.md) |
| COE001006 | Put Spread | [put spread](payoffs/put-spread.md) |
| COE001011 / COE001012 / COE001013 | Digital Call / Digital Put / Double Digital | [digital](payoffs/digital-duplo-indexador.md) |
| COE001045 | Troca de Indexadores | [duplo indexador](payoffs/digital-duplo-indexador.md) (indexer-switch variant) |
| COE001003 | Call KO (with `Rebate no Cenário de Alta`) | [shark fin](payoffs/shark-fin.md) |
| COE001015 / COE001041 | Range Accrual / Wedding Cake | [range accrual](payoffs/range-accrual.md) |
| COE001022 | Put KI | [reverse convertible](payoffs/reverse-convertible.md) (short down-and-in put) |
| COE001009 | Straddle Put KO | [twin win](payoffs/twin-win.md) |
| COE001073 | Call Alavancagens com Limitador | [booster](payoffs/booster.md) (levered capped upside leg) |
| COE001031–34 | Forward / Participation Forward variants | — |
| COE001053 / 57 / 72 / 76 | Retorno Condicional family | no option leg: redemption is principal plus interest against the guaranteed capital |
| COE001078–80, COE001083–86 | COE de Crédito (CDS / TRS variants) | credit-linked COEs (out of scope here) |
| COE001088 | Cesta de Opções | option baskets |

[Autocalls](payoffs/autocall-athena.md) (Athena, [Phoenix](payoffs/autocall-phoenix.md))
are not a single figure: they are registered as a figure plus **Fluxo de Caixa** (the
coupon schedule) and the early-redemption trigger, exercised through the *Indicação de
Disparo de Trigger* function; barrier figures with `Período de Pagamento = Ato` also
settle at the moment the trigger fires (vs `Vencimento`, marked but paid at maturity).

## 5. Early exit and settlement fields

| Field | Description |
|---|---|
| Resgate Antecipado | Registered early-redemption condition — screen options: **Não tem condição de liquidez** (no early redemption), **Liquidez diária a mercado** (redeemable at market conditions on the redemption date), or **Condição específica** (a pre-defined condition, e.g. verification of price levels, detailed in the issuance documents). Effectuation requires double command (counterparty acceptance), except when `Cláusula de Resgate pelo Emissor = Sim` (unilateral issuer call). |
| Resgate antecipado automático | Autocall provisions: dates, triggers, redemption formula per date (see autocall payoffs); the trigger event is commanded via *Indicação de Disparo de Trigger*. |
| Recompra / revenda | Whether and how the issuer offers early buyback at market value (protection does not apply before maturity). |
| Datas de pagamento | Payment dates for interim coupons and final settlement (D+ convention on the B3 cash window). |
| Preço de referência / MtM | B3 discloses reference prices used for statements and portfolio marking (see [calculations.md](calculations.md#5-valuation-and-mark-to-market)). |
